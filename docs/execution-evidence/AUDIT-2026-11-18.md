# Auditoría transversal — 2026-11-18

Revisión del árbol ejecutable completo (`contracts`, `domain`, `identity`, `sales`,
`persistence`, `api`) buscando defectos reales: aislamiento por tenant, permisos,
idempotencia, validación de datos, timeouts, SSRF, fugas de secretos y deriva
entre dominio y esquema. Cada corrección lleva su prueba; abajo se indica el
código y el archivo de prueba.

Comandos de la pasada final:

```bash
pnpm run typecheck                       # EXIT=0
pnpm run test                            # EXIT=0, 302 pruebas / 30 archivos
```

Ocho pasadas sobre el mismo árbol: la primera corrigió 31 defectos, la segunda
13, la tercera 5, la cuarta 6, la quinta 1, la sexta 3, la séptima 4 y la octava
4 (secciones "Segunda pasada" a "Octava pasada"), todos con prueba de regresión.
Total: **67 defectos**.

## Hallazgos no corregidos (decisión pendiente o fuera del host)

- **Impuesto y descuento de pedido**: el código calcula el IVA por línea sobre el
  neto de línea y aplica después el descuento de pedido, así que el descuento de
  pedido no reduce la base imponible. Se corrigió el comentario para que
  describa el comportamiento real; cambiarlo es una decisión fiscal/de producto,
  no un bug mecánico. La tasa del descuento de pedido sí se compara ya contra el
  mandato (#52); lo pendiente es la base de IVA.
- **`approvals.resource_ref`** está aislado por tenant pero no tiene FK al
  recurso: una aprobación puede referenciar un id inexistente. Requiere decidir
  si el recurso es polimórfico o se parte en tablas por tipo.
- **Cursor de importación**: resuelto en la segunda pasada (#43). El cursor
  ahora es `v1:<secuencia>:<token>`; el llamador lo sigue tratando como opaco,
  pero el núcleo ordena por la secuencia y no por el texto. Un cursor de otra
  versión se rechaza en vez de compararse.
- **Migraciones concurrentes**: resuelto en la tercera pasada (#49) con
  `pg_advisory_xact_lock` y relectura dentro del lock, probado sobre PGlite
  (PostgreSQL WASM). Sigue sin probarse contra un Postgres servidor real.
- Sin cambios ni verificación en: Supabase real, `pg` contra servidor real,
  proveedores, envío, firma, cobro, Anam, backups, CI y despliegue. Nada de esta
  auditoría acredita un proveedor.
